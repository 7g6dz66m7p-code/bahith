# bahith
# باحث | BAHITH — Foundation 0.1
نواة المرحلة الأولى، وليست منصة مكتملة أو موقعاً منشوراً.

## التشغيل
Node.js 24 وnpm. لا يلزم مفتاح AI للاختبارات.

```sh
npm ci
npm run check
npm audit --audit-level=high
```

يطبّق اختبار قاعدة البيانات ملف SQL داخل PGlite، وهو محرك PostgreSQL مضمّن. لم يُختبر اتصال خادم PostgreSQL مستقل أو pgvector أو استعادة نسخة احتياطية.

## تطبيق المخطط على قاعدة تطوير جديدة فقط
بعد إنشاء قاعدة فارغة ودور migrations مناسب، مرر DATABASE_URL سراً:

```sh
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f db/migrations/001_foundation.sql
```

المهاجرة مرة واحدة وتفشل عند تكرارها؛ لا تستخدمها على قاعدة قائمة دون مراجعة. ينشأ bahith_app كدور NOLOGIN، ويُمنح لدور اتصال محدود. يلزم سجل migrations/checksum وadvisory lock قبل التشغيل المشترك. لا تنشئ كلمات مرور ثابتة. لا تنفذ rollback بحذف بيانات؛ عند الخطأ أثناء المهاجرة تعمل المعاملة على منع التطبيق الجزئي. بعد نجاحها يكون الإصلاح بمهاجرة أمامية.

## الموجود
- عقود الوكلاء وحالات المهام.
- بوابة بنيوية لصحة الاقتباس والمراجعة، لا تدّعي تقييم الدلالة آلياً.
- مخطط 10 جداول وRLS ومفاتيح مركبة ونواة بحث نصي.
- اختبارات صلاحيات وسلامة أدلة؛ إعداد CI محلي المصدر لم يُشغّل على GitHub.
- وثيقة A–L وبرومبت تنفيذي مستقل وخطة تشغيل.

## غير الموجود بعد
واجهة Next.js، تسجيل الدخول، API، RAG/embeddings، التكاملات الخارجية، OCR، المحرر، التصدير، الفوترة. ملفات البيئة فارغة عمداً. قبل تنفيذها اتبع docs/BAHITH-BLUEPRINT.md وdocs/MASTER-PROMPT.md.
