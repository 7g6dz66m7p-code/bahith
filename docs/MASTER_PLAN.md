# MASTER PLAN

المصدر: أوامر المالك (CLAUDE.md، الأمر التنفيذي، أمر BAHITH 2.0، أمر الإكمال الشامل). الأولوية حسب الاعتماديات:

1. **حماية العمل:** bundle مُتحقق، وثائق الاستئناف (منجز). الدفع إلى GitHub (محجوب).
2. **دمج الأعمال الجارية:** الإشعارات، المكتبة/Zotero، الترحيل/Telegram.
3. **الهوية والوصول:** هاتف + OTP (محايد المزود)، حذف/تصدير الحساب.
4. **التجارة:** Webhooks موقعة، تفعيل idempotent، مطابقة، فواتير (بعد اختيار البوابة).
5. **الذكاء الاصطناعي:** Gateway متعدد مع fallback وstreaming وتكلفة؛ الوكيل متعدد الأدوات؛ تشغيل التقييم الحقيقي عند توفر الرصيد.
6. **الإدارة:** مستخدمون، أخطاء، مهام خلفية، تكاليف.
7. **الأداء:** تشخيص التشبّع (pool، نسخ متعددة)، k6 1/10/50/100.
8. **البنية:** Dockerfiles، Staging، Blue-Green، مراقبة.
9. **الواجهة:** حركة زجاجية خفيفة، صفحات الاشتراكات/الإعدادات.
10. **التدقيق النهائي** وتصنيف كل ميزة.
