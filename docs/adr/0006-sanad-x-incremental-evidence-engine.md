# ADR-0006: تكامل SANAD-X التدريجي وسلسلة منشأ الأدلة

- **الحالة:** مقبول لهذا الجزء المنفّذ؛ المحرك الكامل غير مكتمل
- **التاريخ:** 2026-11-14

## السياق

طلب صاحب المشروع تنفيذ SANAD-X على `claude/new-session-tv7vfk` مع الحفاظ على
الوظائف والعزل وعدم تعديل `main` أو طلب الدمج 1. نسخة الفرع عند `89b6bc5` تحتوي
المرحلة الأولى فقط. المرحلة الثانية، بما فيها Better Auth وجلسات المستخدم، غير
منفّذة. المواصفات المستلمة انقطعت في بداية SANAD Verify؛ أسماء ومتطلبات الوحدتين
الثالثة والرابعة غير متاحة. طلب المواصفات الجديدة يجيز التنفيذ التدريجي رغم ترتيب
المراحل الأقدم في `CLAUDE.md`، ولا يجيز افتراض متطلبات علمية غير مستلمة.

## القرار

1. **تكامل داخلي حقيقي دون مسارات HTTP جديدة:** يصدّر `@bahith/db` خدمتي
   `ingestExtraction` و`retrieve`. `userId` يأتي من مستدعٍ موثوق، ومن جلسة مصادق
   عليها عند إضافة HTTP لاحقاً. لا يُعامل معرّف UUID مصادقة. تتحقق الخدمة من
   العضوية والدور والمشروع داخل المعاملة نفسها، مع أقفال قراءة تحفظ الصلاحية
   طوال العملية، ثم RLS والتحقق الصريح من `workspace_id` و`project_sources`.
   `owner/editor` للكتابة، وكل الأدوار الحالية للقراءة. لم تتغير واجهات الويب القائمة.
2. **الاستخراج الحتمي في عامل Python:** PDF عبر `pypdf`، وDOCX عبر `python-docx`،
   وTXT بترميز UTF-8 الصارم. اختير `pypdf` المرخّص BSD-3-Clause بدلاً من إضافة
   PyMuPDF ذي ترخيص AGPL؛ أدوات الاستخراج لم تكن مثبتة سابقاً. لا OCR ولا تخمين
   للنصوص الفاشلة. يبقى نص الوحدة الأصلي دون تطبيع؛ التطبيع العربي للبحث فقط.
3. **عقد JSON مُصدَر ومتحقق عبر اللغتين:** مخططات Pydantic وZod، تجزئة SHA-256
   للبايتات، وإصدارات المستخرج والتقطيع، ووحدات ومقاطع وفشل صريح. مواضع النص
   تعدّ Unicode code points، لا وحدات UTF-16. يطابق المستقبِل نص كل مقطع مع
   الشريحة الأصلية. صفحات DOCX/TXT تبقى `null`. اتجاه كل مقطع مستقل في النص المختلط.
4. **نسخ المصدر:** الزوج `(fileId, sha256)` يعرّف نسخة الملف. هجرة إضافية قابلة
   للتراجع تضيف `files.extraction` و`chunks.provenance`، وكلاهما اختياري للسجلات
   السابقة. تضم البيانات الإصدار والتجزئة والمواضع وتشخيص الفشل دون نصوص في سجل
   المعالجة. بعد نشر الاستخراج تمنع مشغّلات قاعدة البيانات تعديل نص المقاطع وهوية
   الملف في مكانهما، مع السماح بإعادة التضمين. تتطلب إعادة الاستخراج نسخة ملف
   جديدة. التكرار المطابق يعيد المعرّفات نفسها؛ لا تُحذف المقاطع القديمة أو المستشهد بها.
5. **الاسترجاع:** بحث لفظي بتطبيع عربي وGIN، وبحث cosine عبر pgvector عندما يقدّم
   المستدعي متجه استعلام حقيقياً من النموذج نفسه ذي 1024 بُعداً. يمكن إدخال متجهات
   المقاطع الحقيقية اختيارياً مع الاستخراج. لا ننتج متجهات وهمية. دون متجه الاستعلام
   تعاد `mode: lexical`. دمج RRF بمعامل 60، وترتيب حتمي بالتعادل اللفظي والمعرّف؛
   سقف 200 مرشح لكل مسار و50 نتيجة. عتبة cosine للمرشح الدلالي 0.1 إعداد أولي
   ثابت ومعلن، وليس عتبة جودة علمية مُقاسة. المصادر غير المتحقق منها تبقى موسومة بذلك.
6. **Verify محدود وصريح:** كشف مرشحات ادعاءات عربية/إنجليزية بطريقة heuristic-v1
   مع مواضع أصلية و`needs_human_review`؛ ومطابقة اقتباس حرفية داخل مقاطع مسموحة فقط.
   `exact_quote_match` لا يعني دعم الادعاء أو صحة المصدر علمياً. لا يقبل طلب الاقتباس
   صفحات أو مراجع؛ تؤخذ من بيانات الاسترجاع. لا تنفيذ لتعليمات المستند، ولا اتصال
   بنموذج أو إنترنت أو أدوات كتابة من هذه الوظائف.
7. **الخصوصية والحدود:** أداة استخراج محلية تكتب manifest خاصاً بصلاحية 0600 وترفض
   الكتابة فوق ملف قائم. stdout يحمل التجزئة والأعداد فقط. لا نضيف مهمة طابور تقبل
   مسارات محلية غير موثوقة. الملفات/الـmanifest الحقيقية لا تُضاف إلى المستودع.

## البدائل

- **فتح API بمعرّفات مستخدم من الطلب:** مرفوض لغياب المصادقة؛ RLS وحده لا يثبت هوية المستدعي.
- **إكمال أربع وحدات بتخمين المواصفات:** مرفوض؛ يلزم استلام بقية الطلب.
- **تبديل المكدس أو جلب طلب الدمج 1:** غير لازم ومخالف لنطاق المستخدم.
- **ادعاء بحث دلالي بمتجهات مصطنعة أو إثبات علمي بنموذج:** مرفوض؛ لا توجد تهيئة
  مزوّد/نماذج معتمدة أو أدلة قياس لجودة الاستدلال.

## العواقب والحدود

النواة قابلة للتشغيل والاختبار على ملفات وقاعدة بيانات حقيقيين، وتحافظ على عقود
المرحلة الأولى. لا تمثل تطبيق SANAD-X الكامل: المصادقة والرفع إلى S3 وتشغيل الاستخراج
عبر BullMQ والواجهة ومزود التضمين وإعادة الترتيب بنموذج والقياس العلمي والاستنتاجات
ومسار المراجعة البشرية الدائم لم تُنفذ في هذا الجزء. DOCX لا يوفر ترقيم صفحات ثابتاً؛
الرؤوس والتذييلات ومربعات النص والجداول المتداخلة غير مستخرجة حالياً. أعداد الرموز
تقديرات Unicode معلنة، وليست tokenizer نموذج. لا يجوز احتساب اختبارات البيانات
الاصطناعية الصغيرة كمقياس لاسترجاع الأدبيات أو الصحة العلمية.

قيود الصفحات في مخطط المرحلة الأولى تسمح ببعض حالات النطاق نصف الفارغ بسبب دلالات
SQL NULL؛ المدخلات الجديدة تُرفض عند حد Zod وVerify، ولا تُنسب صفحات إلى الملخصات.
لم تُشدّد قيود السجلات القديمة في هذه الهجرة لتجنب رفض بيانات قائمة دون ترحيل مدروس.
