# تقرير المرحلة الأولى — 2026-11-14

الحكم: PASS للنواة المحلية المحددة؛ PARTIAL للمرحلة الأولى بمعناها السحابي الكامل. لا جاهزية إنتاج.

## الفحص
مساحة العمل الخاصة بهذه الجلسة كانت خالية من مشروع. أُنشئ مجلد bahith ومستودع Git محلي مستقل. لا remote ولا push ولا نشر. Node v24.22.1 وPython3.12.14 متاحان؛ لم يوجد psql/postgres/docker في PATH. توفر تنزيل اعتماديات npm واستخدمت إصدارات مثبتة في lockfile.

## المنفذ
1. وثيقة A–L وبرومبت مستقل، ومصفوفة نطاق ومراحل وقبول وتكلفة وتهديدات.
2. عقود TypeScript للوكلاء وحالات المهام وبوابة بنيوية لصحة الأدلة.
3. migration SQL معاملية تنشئ10 جداول وعضويات وأدوار وRLS وقيود tenant FK وفهرس FTS.
4. منع تعديل نسخ المصادر والمقاطع والادعاءات والأدلة والمراجعات من دور التطبيق.
5. إعداد CI لم يُشغّل على GitHub؛ README وADR و.env.example دون أسرار.

## التحقق الفعلي
- npm ci: اكتمل بنجاح من lockfile.
- npm run check: exit0؛ tsc --noEmit نجح؛ Node test runner أبلغ27 اختباراً ناجحاً،0 فاشل،0 متخطى. العدد يشمل اختبار integration الأب و14 حالة داخله و12 اختبار نواة.
- PGlite نفذ ملف SQL فعلياً. شملت الاختبارات غياب السياق، عزل القراءة، رفض كتابة عبر مساحة أخرى، رفض FK متقاطع، عضوية ناقصة، منع viewer من الكتابة، منع ترقية الدور ذاتياً، ومنع تعديل الأدلة ومراجعتها.
- npm audit --audit-level=high: exit0،0 ثغرات معروفة وقت الفحص؛ هذا ليس تدقيقاً أمنياً شاملاً.
- السجلات: check.log وaudit.log.

## حدود الإثبات
لا خادم PostgreSQL مستقل ولا اختبار pool/network/concurrency أو pgvector أو استعادة backup. لا interface/API/auth/AI provider/RAG/CSL/export/OCR/billing. اختبار gate بنيوي ولا يقيس صدق الاستنتاج. نمط FTS الحالي simple ولا يقدم تحليل صرف عربي. إعدادات CI ليست دليلاً على جولة Actions. لم تُشغّل integration حية أو تنفق استدعاءات AI داخل التطبيق.
