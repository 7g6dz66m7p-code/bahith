## 5. القرارات المعمارية

ADR-0001…0007 (سابقة)، ADR-0008 محرك الاستشهادات (**مقترح** — ترخيص citeproc CPAL/AGPL بانتظار قرار)، ADR-0009 التصدير (**مقترح**)، ADR-0010 الاسترجاع v2 (**مُنفَّذ، بانتظار المراجعة** لأنه يغيّر سلوك البحث).

## 6. المخاطر

- التجذيع الخفيف قد يدمج كلمات مختلفة؛ يحد منه شرط نصف المصطلحات.
- استخراج Chromium: Chromium يكتب مسافات بعرض صفر عند تقسيم المقاطع حول الحركات؛ النص المشكول بالكامل قد يبقى بخطأ مسافة — يحتاج مراجعة بشرية.
- OCR بدقة منخفضة يقرأ بعض الكلمات العربية حروفاً لاتينية؛ الثقة مخزنة ولا عتبة رفض آلية.
- الحصة تُحتسب عند بدء الطلب حتى لو فشل المزود (محافظ).
- زمن الاستعادة مقيس على قاعدة صغيرة فقط.

## 7. العوائق الحقيقية

1. **مفتاح مزود الذكاء الاصطناعي:** مفتاح Claude API لا يمكن حفظه «سراً شبكياً» لمضيفات Anthropic في هذه البيئة؛ يُضاف فقط متغير بيئة `ANTHROPIC_API_KEY` في إعدادات البيئة (يقرؤه كل من يستخدم البيئة وأوامرها) مع `AI_CHAT_MODEL=anthropic:<model>`. البديل: مفتاح OpenAI يمكن حفظه سراً شبكياً. **القرار لصاحب المشروع.**
2. **قيم الحصص:** الخطط في البذور بلا حدود (`{}`) عمداً؛ يلزم تحديد `ai_requests_per_month` لكل خطة.
3. **GitHub:** الدفع مرفوض 403 — إعادة ربط GitHub من claude.ai.
4. **Staging/Production، الدفع، Google OAuth وSMTP الإنتاجي، `SCHOLARLY_CONTACT_EMAIL` الحقيقي.**
