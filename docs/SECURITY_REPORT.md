# SECURITY REPORT

- **العزل:** RLS مفروض (FORCE) على كل جدول بحثي (22)، دور تطبيق بلا BYPASSRLS، فحص عضوية في كل خدمة، اختبار عزل لكل مسار API (غريب 403/404، مجهول 401، أصل آخر 403).
- **المصادقة:** Better Auth، تحقق بريد إلزامي، TOTP، حدود معدل في Postgres، الأدمن يتطلب 2FA.
- **CSRF:** كل تغيير حالة عبر `fetch` مع فحص `Origin` على الخادم (`requireSameOrigin`)، ملفات SameSite، والنماذج POST. تحذير ZAP «Absence of Anti-CSRF Tokens» معلَّل بذلك؛ لا يوجد إرسال نموذج تقليدي يغيّر الحالة.
- **CSP:** مفعّلة للصفحات؛ `'unsafe-inline'` للسكربتات مقايضة معروفة (سكربتات Next المضمنة). التحسين التالي: nonce لكل طلب عبر `proxy.ts`.
- **الملفات:** نوع من البايتات، حد 50MB، SHA-256، CSP sandbox لغير PDF.
- **الذكاء الاصطناعي:** موافقة لكل مشروع قبل إرسال أي نص، مقاطع داخل وسوم بيانات، مجموعة Prompt Injection، إزالة مراجع/صفحات يكتبها النموذج، رفض مقاطع غير مرسلة.
- **الأسرار:** gitleaks في pre-commit وCI؛ المفاتيح أسرار شبكية لا تدخل الكود.
- **السجلات:** بلا محتوى بحثي أو بريد.
- **مفتوح:** حذف الحساب/تصدير البيانات، nonce CSP، فحص ZAP نشط (active scan) على Staging، اختبار اختراق مستقل.
