# eval — مجموعات التقييم العلمي الثابتة

## `pnpm eval` — سَنَد: الاسترجاع ومواضع الأدلة والاقتباسات

مجموعة ثابتة مُصطنعة في `sanad/corpus/corpus.json` (ليست دراسات حقيقية ولا يُستشهد
بها): 4 مستندات، 10 صفحات (عربي، إنجليزي، عربي بمصطلحات لاتينية، ومستند **ممسوح ضوئياً**
يمر بـOCR)، 24 سؤالاً بصفحة ذهبية، 8 أسئلة خارج المصادر، 12 اقتباساً حرفياً صحيحاً،
وتحريفات حتمية لها (رقم مُغيَّر، كلمة محذوفة، كلمتان مُبدَّلتان) و4 اقتباسات مختلقة.

يشغّل المسار الحقيقي: ملفات PDF المُلتزَمة ← مستخرج العامل (pdfium + Tesseract) ←
`ingestExtraction` في Postgres 16 + pgvector حقيقي (Testcontainers) ← `retrieve()` ←
`verifyQuotation()`. يتطلب Docker و`uv` وTesseract (ara+eng).

| المقياس                                                              | العتبة (تُفشل الأمر) |
| -------------------------------------------------------------------- | ------------------- |
| Recall@10 (المقطع من المصدر الذهبي ونطاق صفحاته يغطي الصفحة الذهبية) | ≥ 80%               |
| قبول الاقتباس الصحيح **في صفحته الذهبية**                            | ≥ 90%               |
| القبول الخاطئ (محرَّف أو مختلق)                                        | 0%                  |
| الامتناع على مستوى الاسترجاع (لا مقطع لسؤال خارج المصادر)            | ≥ 85%               |

ويُبلَّغ أيضاً عن Recall@1 وMRR ودقة الصفحة المطابقة تماماً، مفصولة للنص الرقمي وOCR.
**لا يُقاس** (يحتاج مزود نماذج): دقة استشهادات الإجابة، امتناع النموذج، البحث الدلالي.
النتائج في `sanad/results/latest.{json,md}` (غير مُلتزَمة؛ تُنسخ إلى التقارير).

إعادة توليد ملفات PDF بعد تعديل `corpus.json`: `pnpm --filter @bahith/eval eval:corpus`.

## English

`pnpm eval` runs the fixed synthetic SANAD corpus through the real extractor, ingestion,
retrieval and verbatim quote verification, and fails when a gate above is missed.
