# eval — المجموعة الذهبية وتقييم جودة RAG

يُبنى في **المرحلة 3**: مجموعة ذهبية من الأسئلة والمقاطع المرجعية، وسكربت يقيس:

- دقة الاستشهاد (≥ 90%)
- Recall@10 (≥ 0.80)
- الامتناع الصحيح حين لا يوجد دليل (≥ 85%)
- عدد معرّفات المقاطع المختلقة (صفر)

حتى ذلك الحين يفشل `pnpm eval` عمداً برسالة واضحة، ولا يُرجع نتيجة وهمية.
